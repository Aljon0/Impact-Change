# 🌍 Impact Change Website - Frontend

This is the **frontend** of the Impact Change Website.  
Built with **React (Vite)** and styled using **TailwindCSS** for a modern and responsive UI.

The frontend connects to the backend API to handle donations, display content, and send supporter data for email confirmations.

---

## ✨ Features

- 🎨 **TailwindCSS styling** for clean and responsive UI
- 🖥️ **React (Vite)** for fast performance
- 🔗 **Integration with backend API** for donations and emails

---

## ⚙️ Tech Stack

- [React (Vite)](https://vitejs.dev/)
- [TailwindCSS](https://tailwindcss.com/)
- [Axios](https://axios-http.com/) for backend communication
